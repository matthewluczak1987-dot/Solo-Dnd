# Campaigns

One directory per campaign. This is your save file — commit it after each session.

```
campaigns/lost-mine/
  campaign-summary.md    # current state: where you are, what's open
  campaign-log.md        # full session-by-session history
  character-<name>.md    # the PC
  sidekick-<name>.md     # the companion NPC
```

To pick up an existing game, start a session and say **"continue lost-mine"**.
